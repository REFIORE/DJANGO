# Введение в Django

Создали сайт с списком дел с back-end на Django.

## Запуск

- Скачайте код
- Установите зависимости командой `pip install -r requirements.txt`
- Запустите сервер командой `python manage.py runserver`

## Цели проекта

Код написан в учебных целях — это урок в курсе по Python и веб-разработке на сайте [Partacrm](https://crm.partacrm.ru/studentedu/dashboard).
